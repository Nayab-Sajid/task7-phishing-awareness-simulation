# Task 7 – Phishing Awareness Simulation
Internee.pk Cybersecurity Internship

## What this task is about
Educate staff on identifying and avoiding phishing attacks by designing
a test phishing email, tracking how a user interacts with it, and
writing a security awareness report.

## What I did
- Designed a realistic phishing email ("your password expires in 24
  hours") with a fake sender name, urgent wording and a fake link
- Built a safe landing page (instead of a real credential-stealing
  page) that reveals the test and lists phishing red flags
- Sent the email to myself as a self-test and opened it fresh, like an
  unsuspecting employee would
- Noticed Gmail exposed the real sending address, a real giveaway that
  helped confirm the email was not genuine
- Clicked the link and confirmed the full flow worked end-to-end
- Explained how GoPhish's real features (template, landing page,
  sending profile, target list, click/open tracking) map to this
  manual simulation, since installing GoPhish was not possible on
  this browser-only setup
- Documented findings and recommendations in a security awareness
  report

## Tools used
Gmail, CodePen (fake landing page), GoPhish (explained conceptually)
